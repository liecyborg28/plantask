# 🪴 PlanTask – Simple Task Manager with Local Storage

PlanTask is a lightweight web-based task manager that allows users to create, edit, and delete tasks effortlessly. All data is stored using **Local Storage**, meaning no backend or database is required — your tasks remain saved in the browser even after refreshing the page.

---

## ✨ Features

- ➕ **Add Task** – Quickly add new tasks
- ✏️ **Edit Task** – Modify tasks directly from the list
- 🗑️ **Delete Task** – Remove tasks anytime
- 💾 **Local Storage Persistence** – Tasks stay saved automatically
- 🎨 **Minimal & Clean UI** – Simple, modern, distraction-free
- ⚡ **Pure Vanilla JavaScript** – No external frameworks required

## 📦 Installation & Setup

No Node.js, no dependencies, no build tools required.  
Just clone the repository and open the project.

### 1️⃣ Clone the repository

```bash
git clone https://github.com/liecyborg28/plantask.git
```

### 2️⃣ Navigate into the project folder

```bash
cd plantask
```

### 3️⃣ Run the application

```bash
npm run dev
```
